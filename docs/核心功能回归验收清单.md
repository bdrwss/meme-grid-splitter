## 三、推荐的标准化单次回归执行流程

当需要对项目进行一次完整的全流程回归时，建议按以下顺序在 10 分钟内执行完毕：

1. **环境准备**：
   - 执行 `npm run build`，确保 TypeScript 检查与打包无报错。
   - 启动本地服务并用 Chrome 访问干净页面。
2. **示例视频走查**：
   - 点击「快速体验：使用示例视频」，验证文件解析（480×480, 1:1, 2.0s）。
   - 快速点击测试防重复加载保护。
3. **网格与切割全流程**：
   - 依次切换 `2×2`、`3×3`、`3×1`、`1×3` 网格预设，核对切割线与格数。
   - 分别选择 MP4 与 GIF 格式各执行一次完整切割，核对切片卡片展示与播放。
4. **下载与命名走查**：
   - 测试单个下载与 ZIP 打包下载，检查解压内容完整性。
   - 输入带特殊符号或空格的前缀，核对生成的文件名是否合规。
5. **本地视频与更换走查**：
   - 点击「更换视频」，上传本地常规视频，验证流程闭环。
