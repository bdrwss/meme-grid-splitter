## 六、比对方法与本轮踩坑（关键，照做才能得到真实结论）

1. **格式状态必须两边一致**：切到 GIF 后按钮高亮、结果卡片扩展名、提示条文案都会变。
   拿「原站 MP4 态」比「本工程 GIF 态」会凭空产生约 20 项文案差异与 8 处样式差异。
   弹窗态尤其要用 `DRAG=1 CUT=1 DIALOG=1`（**不带** `EXTRAS`）。
2. **含 `<video>` 的状态必须先暂停并 `currentTime=0` 等 `seeked` 再截图**，否则采到的是不同帧。
3. **截图前把动画推进到终态**：`document.getAnimations().forEach(a => a.finish())`，
   并**等到「取消切割」按钮消失（本次切割结束、结果卡片重新挂载完成）**再采弹窗态；
   否则会采到结果卡片 `animate-fade-in` 或 toast 的中间值（如 `opacity 0.895 / translateY 1.05`），
   被误判为样式差异。
4. **无头环境下不要用 `input.uploadFile(宿主路径)`**（渲染进程读不到该文件，
   会报 `NotReadableError`）。改为**同源注入**：页面内 `fetch` 二进制 → `new File()` →
   `DataTransfer` 赋给 `input.files` → 派发 `change`。
5. **弹窗只裁卡片区域比对**：`CROP=464,391,976,549`。
6. 比对**用户提供的截图**时，先对齐视口宽高（本次 1912×914），注意其浏览器滚动条会造成
   内容整体左移约 7px，且可能带有浏览器扩展悬浮钮；这些不属于应用差异。
7. 不要用 `pkill -f` 匹配含自身命令行的模式串（会把自己一起杀掉）。

## 七、复现方式（可重复执行）

```bash

cd build
BASE_URL=http://127.0.0.1:5321/ OUT=build/_ui/ours DRAG=1 CUT=1 EXTRAS=1 DIALOG=1 \
  INJECT=http://127.0.0.1:5321/grid9_meme.mp4 UPLOAD=$PWD/assets/grid9_meme.mp4 node _tools/capture.mjs
BASE_URL=https://app-f9osmt3mxse9.miaoda.online OUT=build/_ui/orig DRAG=1 CUT=1 DIALOG=1 \
  WAIT=4000 node _tools/capture.mjs

# 3) 结构化比对（文案 / 几何 / 计算样式）
python3 _tools/diff-ui.py build/_ui/orig/results.json build/_ui/ours/results.json
```
