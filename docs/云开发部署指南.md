# 云开发部署指南（PRD 登录鉴权与学员库管理）

完成以下 6 步后，小程序即从「离线激活码」模式切换为 PRD 云端模式。**未完成前无需改任何代码**——`utils/config.ts` 的 `CLOUD_ENV_ID` 留空时，现有离线激活码功能完全不受影响。

## 1. 开通云开发环境

1. 微信开发者工具打开本项目 → 顶部工具栏点「云开发」；
2. 同意协议并**创建环境**（记下环境 ID，形如 `cloud1-2g5abc123`）；
   - 注意：云开发为付费服务（基础套餐约 ¥19.9/月），此前"零成本"约束即指此项；
3. 项目根目录的 `project.config.json` 已配置 `"cloudfunctionRoot": "cloudfunctions/"`，开通后左侧会出现 `cloudfunctions` 目录。

## 2. 部署云函数

1. 右键 `cloudfunctions/api` → 「上传并部署：云端安装依赖」；
2. 等待右上角提示部署成功。

## 3. 初始化数据库

任选其一：

- **开发者工具**：云开发控制台 → 数据库 → 手动创建 4 个集合：`users`、`student_pool`、`auth_codes`、`config`；
- **代码调用**：临时在任意页面调用一次：
  ```ts
  wx.cloud.callFunction({ name: "api", data: { action: "initDb" } }).then(console.log);
  ```
  `initDb` 会自动建集合并写入默认管理员口令 `666`（幂等，可重复执行）。

## 4. 建议索引（数据量大后必建）

云开发控制台 → 数据库 → 对应集合 → 索引管理：

| 集合 | 字段 |
| --- | --- |
| `users` | `wx_openid`（唯一）、`xibo_uid`、`role` |
| `student_pool` | `student_uid`（唯一）、`teacher_uid`、`bound_openid`、`batch_no` |
| `auth_codes` | `code`（唯一，集合默认 `_id` 即可）、`status`、`used_by_uid` |

## 5. 启用云端模式

编辑 `miniprogram/utils/config.ts`：

```ts
export const CLOUD_ENV_ID = "cloud1-2g5abc123"; // ← 换成你的环境 ID
```

重新编译。启动时即静默登录（`wx-server-sdk` 在云函数侧直接取 OpenID，无需 `wx.login`/code2Session/弹窗授权）。

## 6. 功能自检清单（对照 PRD）

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 「我的」页连点头像 5 次（2 秒内） | 弹出"管理员验证"密码弹窗 |
| 2 | 输入 `666` 确定 | 进入超级管理员后台；错误的口令提示"指令无效" |
| 3 | 后台-授权码：生成 1 个 | 生成 8 位码并自动复制 |
| 4 | 后台-学员总库：批量录入若干 UID（批次 `test01`，教师留空） | 提示新增数量 |
| 5 | 另一台手机/另一个微信：「我的」→ 登录/绑定 → 我是学员 → 输入其中一个 UID | 绑定成功，显示批次/归属教师 |
| 6 | 教师注册微信：用授权码注册（如需测试，可在总库面板录入教师账号后让其注册，或直接再生成码发给教师微信） | 「我的」出现教师工作台 |
| 7 | 教师-我的学员库：粘贴含步骤 4 相同 UID 的列表导入 | 重复项跳过，不中断 |
| 8 | 教师：对已绑定学员点【解绑微信】→ 学员重新用新微信绑定 | 允许换绑 |
| 9 | 管理员：拉黑该学员 → 学员端重新打开小程序 | 首页与「我的」均全屏拦截"账号已被管理员停用" |
| 10 | 管理员：解封 → 学员恢复正常；禁用某教师 → 该教师端被拦截、其学员数据保留 | 与 PRD 一致 |

## 常见问题

- **提示"网络异常，请检查云开发环境配置"**：`CLOUD_ENV_ID` 未填或与部署环境不一致；云函数未部署。
- **提示"服务异常"**：未执行 `initDb`、集合不存在；或云函数未安装依赖（重新"云端安装依赖"部署）。
- **想回退到离线激活码模式**：把 `CLOUD_ENV_ID` 改回 `""` 即可，旧页面（`pages/bind`、`pages/teacher`）与逻辑完整保留。
- **修改管理员口令**：云开发控制台 → `config` 集合 → `admin` 文档 → 修改 `adminPin` 字段（口令只存云端，前端不可见）。
- **私有数据安全**：数据库权限请保持"仅创建者可读写"以外的方式时须谨慎——本项目所有读写都经云函数（管理员权限校验在函数内），建议集合权限设为**仅云函数可读写**（自定义安全规则：`"read": false, "write": false` 对客户端）。
